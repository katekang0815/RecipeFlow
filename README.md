Customized recipe app

## Tech stack

| Area | Choice |
| --- | --- |
| Language | Swift 5 |
| UI | SwiftUI (`NavigationStack`, `PhotosPicker`) |
| Storage | SwiftData (`Recipe`, `Ingredient`, `Step`) |
| Text from photos | Vision (`VNRecognizeTextRequest`), on-device OCR |
| Unit tests | Swift Testing |
| UI tests | XCTest / XCUITest |
| Tooling | Xcode 26.3, `xcodebuild` and `simctl` from the terminal |
| Minimum OS | iOS 17 |

No third-party dependencies.
